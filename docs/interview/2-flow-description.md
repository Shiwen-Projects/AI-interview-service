# Create Session and Stream Questions

1. 📄 `Preparing`
   - Read the CV, position, and job description.

2. ⚙️ `Generating`
   - Send once when generation starts.
   - The frontend shows a loading state.

3. 💬 `Question`
   - Send each completed question immediately.
   - The frontend displays it and keeps loading.

4. ✅ `Done`
   - All questions are complete.
   - The frontend stops loading.

5. ❌ `Error`
   - Send the error message and stop loading.
